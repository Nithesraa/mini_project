Tracks B & C: Supervised MRMR Feature Selection

Minimum Redundancy Maximum Relevance (MRMR) selects features that maximize mutual information with intrusion target classes while penalizing redundant collinearity with already-selected features:

max [ I(x_j ; y) - (1 / |S|) Σ I(x_j ; x_i) ]
