MATLAB-to-Scikit-Learn Architectural Equivalences

The original study conducted experiments using MATLAB Classification Learner. To ensure publication-grade equivalence in Python, estimators were configured with exact mathematical mappings:

Model Family MATLAB Reference Specification Scikit-Learn Implementation Mathematical Rationale & Equivalence
Decision Tree MaxNumSplits=100, Gini index DecisionTreeClassifier(max_leaf_nodes=101, criterion='gini') A tree with $N$ splits produces at most $N+1$ leaf nodes. Missing values were resolved during preprocessing.
KNN k=10, Euclidean, 1/d² distance weights KNeighborsClassifier(n_neighbors=10, weights=w_custom) Custom weight function $w = 1 / (d^2 + 10^{-10})$ matches MATLAB's squared inverse distance weighting. Wrapped in StandardScaler pipeline.
Gaussian SVM RBF kernel, KernelScale=2.2, C=1.0, OvO SVC(kernel='rbf', gamma=0.1033, C=1.0) MATLAB's kernel scale relates to scikit-learn via $\gamma = 1 / (2\sigma^2) = 1 / (2 \times 2.2^2) \approx 0.1033$. Exact equivalence.
Neural Network Single hidden layer (25 neurons), ReLU MLPClassifier(hidden_layer_sizes=(25,), activation='relu', alpha=0.0) Matches layer topology exactly. Solved via Adam optimizer with zero L2 regularization ($\alpha=0.0$). Wrapped in StandardScaler.
SVM Kernel fitckernel: RFF kernel expansion OneVsOne(RBFSampler(n_components=400) + LinearSVC()) Reproduces MATLAB's Random Fourier Feature kernel expansion ($D=400$) wrapped in One-vs-One multi-class decomposition.
Logistic Regression Kernel Kernelized Logistic Regression OneVsOne(Nystroem(n_components=100) + LogisticRegression()) Nystroem RBF kernel approximation ($D=100$, Rahimi & Recht) mapped to linear logistic regression wrapped in OvO.
